# 📋 CodeRishta – YouTube Channel Registration Form

A simple and beginner-friendly **HTML Registration/Subscription Form** created for the **CodeRishta YouTube Channel**.

This project was built to practice the fundamentals of **HTML forms, tables, input fields, radio buttons, checkboxes, textarea, buttons, and basic page structure**.

## 🚀 Project Overview

The **CodeRishta Registration Form** allows users to enter their personal information, select their interests, choose their registration preference, and submit or reset the form.

> 🎯 This project is created for learning and practicing **HTML fundamentals**.

## ✨ Features

* 👤 Personal Information Form
* 📧 Email Address Input
* 📱 Mobile Number Input
* 🎂 Date of Birth Selection
* 📺 YouTube Channel Subscription Option
* 🎯 Interest Selection using Checkboxes
* 💬 Optional Message Box
* ✅ Agreement Checkbox
* 🔘 Submit & Reset Buttons
* 📱 Basic viewport support for responsive display


## 🛠️ Technologies Used

* **HTML5**
* HTML Forms
* HTML Tables
* Input Elements
* Radio Buttons
* Checkboxes
* Textarea
* Buttons
* Fieldset & Labels


## 📸 Form Sections

The form contains:

1. **Personal Information**

   * Full Name
   * Email Address
   * Mobile Number
   * Date of Birth

2. **Registration Preference**

   * Subscribe to CodeRishta YouTube Channel
   * General Registration

3. **Your Interests**

   * Web Development
   * Programming
   * Tutorials
   * Placements
   * Coding
   * Projects
   * Tech News
   * Other

4. **Message**

   * Optional message section
   * Agreement to receive updates
